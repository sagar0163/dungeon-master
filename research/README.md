# Research & Out-of-Spec Ideas

This directory contains experimental code and concepts that were drafted but ultimately fell outside the scope of the core Dungeon Lord Specification (SPEC.md).

These include ideas related to:
- NPCs and Crafting (`CrafterNPC.cs`, `CraftingManager.cs`)
- Complex Item & Ability Databases (`ItemDatabase.cs`, `AbilityDatabase.cs`)
- Market & Economy simulation (`MarketManager.cs`)

They are preserved here for future reference or potential expansions, but they are not currently wired into the game's architecture.
